# 功能闭环

## 所有权
- 行情：浏览器直接访问东方财富公开接口；内存缓存，不持久保存整套行情。
- 自选、笔记、快照：当前浏览器、当前网站源的 IndexedDB，单个 readwrite 事务读取最新版本再写入。GitHub Pages 只托管静态代码，不接收记录。
- 跨页面同步：BroadcastChannel 提交后通知；窗口重新获焦时重读。编辑版本比较在事务中进行。
- 表单：页面内按股票隔离，切股和切标签不丢草稿；刷新丢弃未保存草稿。

## 状态与恢复
| 场景 | 行为 |
|---|---|
| 首次打开 | 默认关注隆基、记录为空；行情加载，来源及时点显示 |
| 刷新中 | 保留当前股票上次成功的数据；按钮显示更新中 |
| 部分失败 | 成功区块更新；失败区块保留旧数据并标记，允许重试 |
| 连续切股 | 请求代次和取消标记阻止旧响应写入；在途网络至多 8 秒并允许缓存复用 |
| 本机存储不可用 | 显示错误和重新加载入口，禁止保存，不伪造成功 |
| 保存失败 | 保留表单，允许修正或重试 |
| 编辑冲突 | 拒绝旧版本，不覆盖另一页面内容；草稿仍保留 |
| 删除 | 行内确认，版本不匹配拒绝；自选移除不删笔记 |
| 导入 | 10 MB 上限，格式和网址校验；预览数量后合并；保留本机同 ID 内容 |
| 错误备份/存储损坏 | 保留现有存储，不静默重置 |
| 其他设备 | 不自动同步，使用 JSON 导出与导入 |

## 验证矩阵
领域测试：缺失数字、单季换算边界、无效代码、坏行情行、部分刷新、000001 个股/指数区分。
事务测试：首次使用、保存后重读、编辑保留快照、删除、并发写入、冲突保护、导入往返/去重、无效备份/不安全链接拒绝、存储拒绝和恢复。
浏览器：真实跨域行情、编辑保存重开、导出导入、切股草稿隔离、桌面/手机视觉；结果记录在 HANDOFF.md。

## 开销
行情缓存 45 秒、历史 5 分钟、财报 1 小时、公告 10 分钟；相同请求共享在途结果，缓存最多 160 项。每个上游请求 8 秒截止。自动刷新由用户开启，仅页面可见时每 60 秒执行。无自建后端、无定时云计算、无外部字体或图片。未验证大规模并发和第三方接口长期稳定性。
